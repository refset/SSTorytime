About

A static-site, browser-only viewer for SSTorytime. All design and ideas are by Mark Burgess; this UI is an alternative delivery mode that runs the same N4L parser in WebAssembly and stores the parsed graph in your browser via PGlite.

How it works

  1. You sign in with Google and pick a folder in your Drive.
  2. The app reads .n4l files and other assets from that folder.
  3. The N4L parser, compiled to WebAssembly, runs in your browser tab.
  4. An in-browser Postgres (PGlite, also WASM) stores parsed data in IndexedDB.
  5. A .sstaas-index.json file in your Drive folder tracks what's been indexed and what's archived.
  6. Pressing Re-index diffs the folder against that meta and processes anything new or changed.

What runs where

  • The hosting domain serves only static files. No server-side application logic, no database, no logs of your activity beyond whatever the static host records.
  • Your browser holds the parsed graph (IndexedDB via PGlite) and the OAuth access token (in memory only).
  • Google Drive holds the canonical N4L and asset files. Drive is the source of truth; the in-browser DB is a derived index.
