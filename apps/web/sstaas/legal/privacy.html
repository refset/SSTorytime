Privacy

Version 2026-04-23

Summary

This application is delivered as static files from a content host (e.g. GitHub Pages). All application logic runs in your browser. The maintainers do not operate any backend service that processes or stores your data.

What data is collected

  • By this application: none. No analytics, no telemetry, no remote logging.
  • By the static host: standard web request metadata (IP, user agent, requested path) per the host's policy. The maintainers don't access those logs.
  • By GitHub: when you use a personal access token (PAT) to load or save files, GitHub records that API activity per their own privacy policy. The app only talks to the repositories whose contents your PAT allows it to reach.

Where your data lives

  • Source N4L and asset files: in the GitHub repository you connect.
  • Parsed graph: in your browser, in IndexedDB via PGlite. It's derived data — clearing browser storage is safe; press Re-index to rebuild.
  • GitHub personal access token: in localStorage on your device so it survives reloads. Clearing browser storage or signing out removes it. Treat it like any other credential and revoke it from GitHub if your device is compromised.

What the application can see

Only the GitHub repositories and paths your PAT grants access to, and only while that token is present in your browser. You can revoke the token at any time from your GitHub personal access tokens page.
