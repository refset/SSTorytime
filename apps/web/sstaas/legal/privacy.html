Privacy

Version 2026-04-22

Summary

This application is delivered as static files from a content host (e.g. GitHub Pages). All application logic runs in your browser. The maintainers do not operate any backend service that processes or stores your data.

What data is collected

  • By this application: none. No analytics, no telemetry, no remote logging.
  • By the static host: standard web request metadata (IP, user agent, requested path) per the host's policy. The maintainers don't access those logs.
  • By Google: when you sign in and grant Drive access, Google records that activity per their own privacy policy. The OAuth scope used is https://www.googleapis.com/auth/drive.file, which restricts the app to files you explicitly open or create through it.

Where your data lives

  • Source N4L and asset files: in your Google Drive folder.
  • Parsed graph: in your browser, in IndexedDB via PGlite. It's derived data — clearing browser storage is safe; press Re-index to rebuild.
  • OAuth access token: in memory only, cleared on refresh.

What the application can see

Only files within the Drive folder you pick, and only while you're signed in. The app cannot see files in other folders. Revoke access at any time from your Google account permissions page.
